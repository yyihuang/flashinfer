# Experimental fused QK RMSNorm, RoPE, and paged KV append

This JIT-only backend fuses packed-QKV unpacking, optional per-head Q/K
RMSNorm, NeoX RoPE, Q output production, and paged K/V cache append. The FP8
variant additionally quantizes Q/K/V in the same launch and supports dynamic
per-token/per-Q-head or static Q scaling.

It fills a narrow gap in current FlashInfer: the stable tree has QK
RMSNorm+RoPE and RoPE+FP8 paged-append primitives, but does not combine the
complete serving preprocessing path into one GQA launch.

Limitations:

- SM90 and SM100 only;
- BF16 packed input;
- Q/K/V head dimension 128;
- `(num_q_heads, num_kv_heads)` is `(8, 1)` or `(64, 8)`;
- NHD cache layout `[page, page_size, kv_head, head_dim]`;
- FP8 cache type is E4M3 and K/V scales are scalar;
- JIT only, no automatic routing and no AOT registration.

## Backends (FP8 entry)

`fused_qk_rmsnorm_rope_quantize_fp8_append_paged_kv_cache(..., backend=...)`
accepts two implementations with the same argument contract, validation
errors, default allocations, and `(out_q, q_scale, split_k_flag)` return:

- `backend="hpc"` (default): the kernel ported from Tencent hpc-ops
  (`csrc/hpc_rope.cu`). One call issues a `split_k_flag` memset, a
  `q_indptr` validation kernel for dynamic prefill quantization, and the main
  kernel.
- `backend="cake"`: a kernel generated by the Cake compiler from its
  `flashinfer_blackwell_fused_qk_rmsnorm_rope_fp8_paged_kv_append` kernel program.
  One call is a single launch: the kernel validates `q_indptr` itself and
  writes every `split_k_flag` entry (0 valid, -1 invalid, including empty
  requests), so no host-side memset or validation kernel is issued. The
  generated body is compiled per exact architecture from
  `csrc/cake/<arch>/fused_qk_rmsnorm_rope_fp8_paged_kv_append_kernel.cu`
  (`sm_90a` for CC 9.0, `sm_100a` for CC 10.0, `sm_103a` for CC 10.3; other
  devices raise). `csrc/cake/cake_fused_qk_rope_append_binding.cu` performs
  the same TVM-FFI shape/dtype checks as the hpc entry. `out_k`/`out_v` must
  be passed together on this backend.

The BF16 entry has no backend selector.

Cake source provenance: Cake commit `050b9eab51e`, render of the
